## 2. ADC1

```c
hadc1.Instance               = ADC1;
hadc1.Init.ScanConvMode      = ADC_SCAN_ENABLE;
hadc1.Init.ContinuousConvMode= DISABLE;
hadc1.Init.DiscontinuousConvMode = DISABLE;
hadc1.Init.ExternalTrigConv  = ADC_EXTERNALTRIGCONV_T3_TRGO;
hadc1.Init.DataAlign         = ADC_DATAALIGN_RIGHT;
hadc1.Init.NbrOfConversion   = 2;
```

Regular sequence:

| Rank | Channel | Pin | Sampling time |
| --- | --- | --- | --- |
| 1 | `ADC_CHANNEL_0` | PA0 (ECG conditioned analog) | `ADC_SAMPLETIME_55CYCLES_5` |
| 2 | `ADC_CHANNEL_1` | PA1 (temperature analog) | `ADC_SAMPLETIME_55CYCLES_5` |

GPIO side (`HAL_ADC_MspInit`): PA0 + PA1 set to `GPIO_MODE_ANALOG`; ADC1 clock enabled via
`__HAL_RCC_ADC1_CLK_ENABLE()`.

**Timing headroom check.** One conversion = (55.5 + 12.5) ADC cycles = 68 cycles.
At 12 MHz that is 5.67 µs per channel, 11.3 µs for the 2-channel scan — about **1.1 %**
of the 1000 µs trigger period. The sequence always finishes long before the next TIM3
TRGO, so no overrun is expected at 1 kHz.

Not configured (CubeMX defaults, correct to leave alone in Phase 0): no watchdog, no
injected/ranked overrun handling, no ADC end-of-conversion interrupt, DMA transfer count
unknown (no buffer declared).

## 3. TIM3 — the 1 kHz sample trigger

```c
htim3.Instance                 = TIM3;
htim3.Init.Prescaler           = 71;
htim3.Init.Period              = 999;
htim3.Init.CounterMode         = TIM_COUNTERMODE_UP;
htim3.Init.ClockDivision       = TIM_CLOCKDIVISION_DIV1;
htim3.Init.AutoReloadPreload   = TIM_AUTORELOAD_PRELOAD_DISABLE;
sClockSourceConfig.ClockSource = TIM_CLOCKSOURCE_INTERNAL;
sMasterConfig.MasterOutputTrigger = TIM_TRGO_UPDATE;
sMasterConfig.MasterSlaveMode  = TIM_MASTERSLAVEMODE_DISABLE;
```

TIM3 sits on APB1, whose timer clock is 72 MHz (see §1):

```
f_update = 72 000 000 / (PSC + 1) / (ARR + 1)
         = 72 000 000 / (71 + 1) / (999 + 1)
         = 72 000 000 / 72 / 1000
         = 1 000 Hz          → period 1 ms
```

`HAL_TIM_Base_MspInit` only calls `__HAL_RCC_TIM3_CLK_ENABLE()`. **No TIM3 NVIC entry is
enabled and no `TIM3_IRQHandler` exists in `Core/Src/stm32f1xx_it.c`.** That is intended:
normal acquisition must not depend on a timer ISR.

`AutoReloadPreload` is **DISABLE**. Harmless while PSC/ARR are fixed at 71/999, but if a
future revision changes the sample rate at runtime, ARR writes will take effect mid-period
instead of at the next update event. Flagged for the reviewer, deliberately not changed.

## 4. DMA1 Channel 1 (ADC1)

| Parameter | Value | `.ioc` key |
| --- | --- | --- |
| Request | ADC1 | `Dma.Request0=ADC1`, `Dma.RequestsNb=1` |
| Instance | `DMA1_Channel1` | `Dma.ADC1.0.Instance` |
| Direction | peripheral → memory | `DMA_PERIPH_TO_MEMORY` |
| Mode | **circular** | `DMA_CIRCULAR` |
| Peripheral increment | disabled | `DMA_PINC_DISABLE` |
| Memory increment | enabled | `DMA_MINC_ENABLE` |
| Peripheral width | half-word (16-bit) | `DMA_PDATAALIGN_HALFWORD` |
| Memory width | half-word (16-bit) | `DMA_MDATAALIGN_HALFWORD` |
| Priority | low | `DMA_PRIORITY_LOW` |

Bound to the ADC in `HAL_ADC_MspInit()` via `__HAL_LINKDMA(adcHandle, DMA_Handle, hdma_adc1)`.
Controller clock and interrupt come from `MX_DMA_Init()`:

```c
__HAL_RCC_DMA1_CLK_ENABLE();
HAL_NVIC_SetPriority(DMA1_Channel1_IRQn, 0, 0);
HAL_NVIC_EnableIRQ(DMA1_Channel1_IRQn);
```

`stm32f1xx_it.c` provides the vector:

```c
void DMA1_Channel1_IRQHandler(void) { HAL_DMA_IRQHandler(&hdma_adc1); }
```

**Expected future memory layout** — because rank 1 is ADC channel 0 and rank 2 is channel 1,
each trigger appends two half-words, so the buffer reads as an interleave:

```
[ECG0][TEMP0][ECG1][TEMP1][ECG2][TEMP2] ...
 ^ even indices = PA0 ECG   ^ odd indices = PA1 temperature
```

No buffer is declared, `HAL_ADC_Start_DMA()` is never called, and therefore **no DMA
interrupt can fire in this baseline**. The vector exists but is dormant.

## 5. I2C1 — planned OLED interface

```c
hi2c1.Instance         = I2C1;
hi2c1.Init.ClockSpeed  = 400000;                  /* 400 kHz Fast Mode */
hi2c1.Init.DutyCycle   = I2C_DUTYCYCLE_2;
hi2c1.Init.OwnAddress1 = 0;                       /* master-only, unused */
hi2c1.Init.AddressingMode = I2C_ADDRESSINGMODE_7BIT;
hi2c1.Init.DualAddressMode = I2C_DUALADDRESS_DISABLE;
hi2c1.Init.GeneralCallMode = I2C_GENERALCALL_DISABLE;
hi2c1.Init.NoStretchMode   = I2C_NOSTRETCH_DISABLE;
```

PB6 = SCL, PB7 = SDA, both `GPIO_MODE_AF_OD` at `GPIO_SPEED_FREQ_HIGH`.
`.ioc`: `I2C1.I2C_Mode=I2C_Fast`.

**I2C1 has no NVIC entry** — event/error interrupts are not enabled, so a future OLED driver
must use the blocking `HAL_I2C_Master_Transmit()`/`HAL_I2C_Mem_Write()` calls, or a later
CubeMX revision must enable the I2C1 interrupts. No driver is added in Phase 0.

The display is planned as a 0.96-inch monochrome OLED. Its controller (**SSD1306 or SH1106**)
and its 7-bit address are **not** frozen — nothing in this repository proves either.

## 6. USART1 — planned PC link

```c
huart1.Instance       = USART1;
huart1.Init.BaudRate  = 230400;
huart1.Init.WordLength= UART_WORDLENGTH_8B;      /* 8 data bits */
huart1.Init.StopBits  = UART_STOPBITS_1;         /* 1 stop bit  */
huart1.Init.Parity    = UART_PARITY_NONE;        /* no parity   */
huart1.Init.Mode      = UART_MODE_TX_RX;
huart1.Init.HwFlowCtl = UART_HWCONTROL_NONE;     /* flow control disabled */
huart1.Init.OverSampling = UART_OVERSAMPLING_16;
```

PA9 = TX (`GPIO_MODE_AF_PP`, high speed), PA10 = RX (`GPIO_MODE_INPUT`, `GPIO_NOPULL`).
`.ioc`: `USART1.BaudRate=230400`, `USART1.VirtualMode=VM_ASYNC`.

**USART1 has no NVIC entry and no TX/RX DMA stream** — the link is polled-only unless a later
revision changes it. No frame protocol is defined in Phase 0.

Baud error note for the reviewer: 230400 from an 72 MHz APB2 clock with `OVERSAMPLING_16`
gives `USARTDIV = 72e6/(16·230400) = 19.53125`, rounded to 19 + 8/16 → 230769 bit/s,
a **+0.16 %** deviation. Well within tolerance.

## 7. RTC

Enabled through the virtual pin `VP_RTC_VS_RTC_Activate.Mode=RTC_Enabled`.

```c
hrtc.Instance           = RTC;
hrtc.Init.AsynchPrediv  = RTC_AUTO_1_SECOND;
hrtc.Init.OutPut        = RTC_OUTPUTSOURCE_ALARM;
```

`HAL_RTC_MspInit()` performs the backup-domain unlock:

```c
HAL_PWR_EnableBkUpAccess();
__HAL_RCC_BKP_CLK_ENABLE();
__HAL_RCC_RTC_ENABLE();
```

Clock source is LSE (see §1). Planned future use is to keep, display and set date/time and to
survive main-power loss on VBAT. **No `HAL_RTC_*` application call exists** and no calendar
time is ever set. `RTC_AUTO_1_SECOND` makes the HAL pick the 32768/1 second division itself;
this is the F1 CubeMX default.

No RTC interrupt/Alarm NVIC entry is enabled.

## 10. Peripheral init order in `main()`

`.ioc` key `ProjectManager.functionlistsort` and `Core/Src/main.c` agree:

```
SystemClock_Config → MX_GPIO_Init → MX_DMA_Init → MX_ADC1_Init
→ MX_RTC_Init → MX_TIM3_Init → MX_I2C1_Init → MX_USART1_UART_Init
```

`MX_DMA_Init()` before `MX_ADC1_Init()` matters: `HAL_ADC_MspInit` initialises the DMA
stream and `__HAL_LINKDMA`, while the NVIC setup lives in `MX_DMA_Init`.
